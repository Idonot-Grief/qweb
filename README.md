# qweb
AKA Qt Web Browser, A modular and simple web browser built on Python and Qt5
It has the basic features that everyone excpects from a web browser without the clutter.
It has JS, WebSocket support, WebGL, bookmarks, Tabs, Quick Search.
It also has a modular ui, letting you rearrange where elements are on the screen, like moving the tabs to the side, or putting the address bar on the bottom.
